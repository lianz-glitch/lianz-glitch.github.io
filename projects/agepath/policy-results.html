Additional observations, fitted as points

Eight L3 applications now fit the published point estimates while preserving their exact L2 restrictions. The income and fiscal mappings remain fixed within each application.

One path-construction rule

Θ̂i,L = arg minθᵢ ∈ Θᵢ,ₗ [m̂i,L − gi,L(θᵢ)]′ Wi,L [m̂i,L − gi,L(θᵢ)],   L = 2, 3

The restriction set contains the anchor, logistic shape, calibrated support, attainment limits and credential ordering where relevant. L3 preserves the exact L2 observations and adds separately reported point targets. Within each of these eight cases, W is the identity matrix; standard errors do not set fitting weights or acceptance bands.

Exact matches minimize the criterion when attainable. These eight searches each retain one best-fitting path with nonzero residuals. This is a conditional fit, not proof of unique identification or global optimality. Five other L3 applications retain exact-match path ranges.

Input uncertainty remains separate

Public-college spending, Texas tuition, tuition caps, Tennessee Promise and cannabis each refit 1,000 registered input perturbations. Tuition caps has 1,000 verified monetary fits and 998 defined MVPFs. Florida, Wisconsin and Kalamazoo lack complete joint L3 draws; no full-L3 uncertainty interval is imputed. The paper reports the inputs varied and the limits of these conditional summaries.
